# Work

In progress. Nothing here is agreed or delivered.

**What goes here.** Draft decks, generation scripts, half-finished documents, exploratory writing, anything being iterated on.

**Rules.**

- Do not cite anything in this folder as a position. It is a draft until it moves to `../delivered/`.
- Deck generation scripts live here alongside their output so a deck can be rebuilt rather than hand edited.
- When something is delivered, copy it to `../delivered/` with a date and a version. Leave the working file here.
- Log the delivery in `../notes.md`.

**Build stack.** `.pptx` via pptxgenjs. PDF conversion via LibreOffice. Text QA via markitdown. Liberandum palette: PINK `#D02E5E`, NAVY `#123C64`.
