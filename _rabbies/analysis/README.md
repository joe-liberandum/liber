# Analysis

Data work. Internal, not client facing.

**What goes here.** GA4 pulls and exports, backlog exports, booking window models, RICE scoring sheets, spreadsheets, scratch calculations, anything where a number is derived.

**Rules.**

- Keep the raw input alongside the output. If a figure appears in a deck, someone must be able to re-derive it from this folder.
- Excel workbooks use live formulas, not pasted values, wherever a chart or a model is involved.
- Name files `YYYY-MM-DD_short-slug_vN.ext`.
- If a number cannot be sourced, say so rather than estimating it.

**Standing caution.** GA4 is accurate but booking-anchored. It reports the final act, not the consideration window. Read the measurement notes in `../research/findings.md` before drawing a behavioural conclusion from it.
